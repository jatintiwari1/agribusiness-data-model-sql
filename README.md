# Agribusiness Data Model & SQL Analytics

## Project Overview

This project presents a comprehensive relational database and SQL analytics solution designed for agribusiness operations. The system organizes and analyzes data related to farms, fields, crops, planting cycles, harvests, labour, equipment, suppliers, purchases, markets, sales, price history, weather conditions, and expenses.

The main objective of this project is to demonstrate how a structured relational database can support agricultural data management and business analysis. The database model is designed to maintain relationships between different operational entities while enabling meaningful analytical queries.

## Key Features

- Farm and field management
- Crop and planting cycle tracking
- Harvest and yield analysis
- Labour and employee management
- Equipment usage tracking
- Supplier and input purchase management
- Market and sales analysis
- Crop price trend analysis
- Weather data management
- Expense and profitability analysis
- SQL-based business intelligence queries

## Database Design

The database follows a relational model with primary keys and foreign keys used to establish relationships between entities.

The major entities include:

- Farm
- Field
- Crop
- Planting
- Harvest
- Employee
- Labor
- Equipment
- Equipment_Usage
- Supplier
- Input_Purchase
- Market
- Sale
- Price_History
- Weather_Log
- Expense

The Planting entity acts as an important link between fields, crops, and harvest activities.

## SQL Analytics

The project includes SQL queries for:

1. Total and average crop yield
2. Yield per hectare
3. Farm-level revenue and profitability
4. Crop price trends by market
5. Changes in recorded market prices
6. Labour hours and labour cost analysis
7. Equipment utilization
8. Supplier spending analysis
9. Best-selling crop analysis by market
10. Rainfall and yield analysis
11. Declining harvest yield trends
12. Top buyers by market

The queries demonstrate the use of JOINs, aggregate functions, filtering, grouping, window functions such as LAG() and ROW_NUMBER(), and analytical SQL techniques.
